# Уфанет Видеодомофон для Home Assistant

Панель Ufanet в Home Assistant — это устройство конкретной двери. На нём картинка с камеры, кнопка открытия и звонок. Устройство называется адресом панели.

Гость нажимает вызов. Включается датчик «Идёт вызов», а в уведомлениях остаются камера этой двери и кнопка открытия. Своего push у панели нет: история вызовов проверяется каждые 15 секунд. Если в настройках заполнен SIP-монитор, вызов приходит сразу и Home Assistant снимает трубку.

В потоке камеры запрашивается и микрофон панели, поэтому там может быть слышно гостя. Голос в динамик двери идёт отдельно, через SIP, кодеком PCMA. Логин монитора регистрируется только в одном месте: пока им пользуется Home Assistant, приложение «Мой Умный Дом» на этот логин не ответит.

В списке интеграций название — **Уфанет Видеодомофон**. Домен по-прежнему `ufanet`, уже добавленную запись удалять не нужно.

## Требования

- Home Assistant 2025.2.4 или новее
- Договор Ufanet с доступом к домофону
- Чтобы Home Assistant снимал трубку — SIP-монитор из приложения «Мой Умный Дом»

## Установка

### HACS

1. **HACS** → **Интеграции** → **Пользовательские репозитории**
2. Добавьте `https://github.com/kligli/ufanet_intercom_ha`, тип **Интеграция**
3. Установите **Уфанет Видеодомофон**
4. Перезапустите Home Assistant

Версия написана в установленных файлах. Чтобы увидеть новую версию и новое название, обновите интеграцию в HACS и перезапустите Home Assistant.

### Вручную

Скопируйте папку `custom_components/ufanet` в `custom_components` Home Assistant и перезапустите его.

## Настройка

1. **Настройки** → **Устройства и службы** → **Добавить интеграцию**
2. Выберите **Уфанет Видеодомофон**
3. Войдите одним из способов:
   - **Номер договора + пароль** — данные личного кабинета
   - **По звонку** — номер телефона договора. Интеграция покажет номер: позвоните на него с этого телефона и нажмите подтверждение
4. Подтвердите вход

После входа появляются учётная запись договора и устройство каждой панели: кнопка открытия, камера, событие звонка, датчик «Идёт вызов» и время последнего звонка.

## Использование

### Дверь

Кнопка открытия нажимается с карточки устройства, из автоматизации и со сценария.

### Звонок на телефон

Уведомление внутри Home Assistant появляется само. Чтобы снимок и кнопка открытия пришли на телефон, после перезапуска создайте автоматизацию из шаблона **Ufanet doorbell** (`config/blueprints/automation/ufanet/visit.yaml`): событие звонка, камера, кнопка двери и сервис телефона (`mobile_app_…` без приставки `notify.`).

Если панелей несколько, событие звонка ждёт историю вызовов и срабатывает у той двери, с которой звонили. Датчик «Идёт вызов» и уведомление в Home Assistant включаются сразу.

### SIP-монитор

**Настройки → Устройства и службы → Уфанет Видеодомофон → Настроить.**

На шаге **SIP-монитор**:

- **SIP-логин** и **SIP-пароль** — из «Мой Умный Дом»: домофон, настройки, «Подключение SIP мониторов», «Подключить монитор»
- **SIP-сервер** и **SIP-порт** — адрес вашего сервера. Пустые поля означают `81.30.201.150` и `5401`
- Пустой логин оставляет монитор выключенным

Дальше для каждой панели подтвердите камеру. Адрес, порт и пароль сохраняются на последнем шаге.

### Камера

Камера стоит на том же устройстве, что и кнопка двери. Другую камеру можно выбрать на шаге **Настроить**, сразу после SIP. «—» оставляет панель без видео. Подставленная камера — та, которую кабинет Ufanet уже связал с панелью.

Пример карточки:

```yaml
type: picture-entity
entity: camera.<панель>
camera_view: live
```

Рядом имеет смысл поставить кнопку открытия этой же панели.

## Безопасность

Пароль кабинета, refresh-токен и пароль SIP хранятся в Store Home Assistant, не в `config_entries`. Данные уходят только в Dom API и на указанный SIP-сервер.

## Если что-то не работает

**Просит войти снова.** Повторите пароль или сценарий звонка в окне повторной авторизации. Запись интеграции удалять не нужно.

**«Invalid login or password».** Проверьте номер договора и пароль и что в кабинете Ufanet видны домофоны.

**Нет камеры.** Проверьте доступ к камерам в кабинете и что у панели заполнен `cctv_number`, либо выберите камеру в **Настроить**.

**Нет домофонов.** Проверьте доступ договора и связь с `dom.ufanet.ru`.

**Название или версия не изменились.** Обновите интеграцию в HACS и перезапустите Home Assistant. Удаление устройства оставляет установленные файлы на месте.

**SIP не звонит в Home Assistant.** Проверьте логин, пароль, адрес и порт и что этот монитор не зарегистрирован в приложении одновременно. В приложении должна быть разрешена регистрация SIP-мониторов.

## Разработка

```bash
git clone https://github.com/kligli/ufanet_intercom_ha.git
cd ufanet_intercom_ha
pip install -r requirements.txt
python3 -m ruff check .
python3 -m pytest tests/test_sip.py tests/test_helpers.py tests/test_calls.py -q
```

```
custom_components/ufanet/
├── __init__.py       # запись, устройства, SIP и уведомление о визите
├── api.py            # Dom API
├── calls.py          # история вызовов и имена панелей
├── coordinator.py    # опрос истории
├── config_flow.py    # вход и настройки
├── camera.py         # камера
├── button.py         # дверь и ответ на SIP
├── event.py          # событие звонка
├── binary_sensor.py  # «Идёт вызов»
├── sensor.py         # время последнего звонка
├── sip.py            # SIP-монитор
├── visit.py          # уведомление и шаблон автоматизации
├── manifest.json
└── strings.json
```
